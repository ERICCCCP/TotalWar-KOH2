# TotalWar - Knights of Honor II Mod

TotalWar 是一个为《Knights of Honor II》设计的全面修改 mod，同时包含 BepInEx 引擎扩展插件。

## 功能特性

### 引擎扩展（BepInEx 插件）
- **朝圣路线机制** - 新增朝圣路线加成系统
- **十字军优先级优化** - 改进 AI 十字军目标选择逻辑
- **圣地控制 buff** - 控制耶路撒冷的王国获得宗教士气加成
- **宗教 UI tooltip** - 显示圣地控制的增益信息

### Mod 内容
- 驻军系统重做
- 贸易收入分级系统
- 维护费公式调整
- 速度系统优化
- 战斗模拟参数调整
- 以及更多...

## 安装

### 引擎扩展安装
1. 从 [Releases](https://github.com/ERICCCCP/TotalWar-KOH2/releases) 下载 `TotalWar_BepInEx_Installer.zip`
2. 解压后双击运行 `install.bat`
3. 脚本会自动检测 Steam 游戏路径并完成安装

### Mod 安装
在 Steam Workshop 订阅 TotalWar mod 即可自动安装。

## 卸载
- **引擎扩展**：删除游戏目录下的 `winhttp.dll` 和 `BepInEx\` 文件夹
- **Mod**：在 Steam Workshop 取消订阅即可

## 系统要求
- Knights of Honor II (Steam 版)
- BepInEx 5.4.x（安装包已包含）
