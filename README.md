# TotalWar - Knights of Honor II Mod

TotalWar is a comprehensive modification for Knights of Honor II: Sovereign, including both a BepInEx engine extension plugin and Steam Workshop content.

## Features

### Engine Extension (BepInEx Plugin)
- **Pilgrim Route System** - New pilgrimage route bonus mechanics
- **Crusade Priority Optimization** - Improved AI crusade target selection logic
- **Holy Land Control Buff** - Kingdoms controlling Jerusalem receive religious morale bonuses
- **Religion UI Tooltip** - Displays Holy Land control buff information
- **Estate System** - 6 social estates (Peasant, Merchant, Clergy, Nobility, Military, Royal) with settlement-based income buffs
- **Vassal Protection** - Prevents vassalage breaking when same-overlord vassals conflict
- **Opinion System Rework** - Balanced opinion modifiers with ±5 range compensation

### Mod Content
- Garrison system overhaul
- Tiered trade income system
- Upkeep formula adjustments
- Speed system optimization
- Battle simulation parameter tuning
- And more...

## Installation

### Engine Extension
1. Download `TotalWar_BepInEx_Installer.patch7.zip` from [Releases](https://github.com/ERICCCCP/TotalWar-KOH2/releases)
2. Extract and run `install.bat`
3. The script auto-detects your Steam game path and completes installation

### Mod Content
Subscribe to TotalWar on Steam Workshop for automatic installation.

## Uninstallation
- **Engine Extension**: Delete `winhttp.dll`, `doorstop_config.ini`, and the `BepInEx\` folder from your game directory
- **Mod**: Unsubscribe from Steam Workshop

## System Requirements
- Knights of Honor II: Sovereign (Steam version)
- BepInEx 5.4.x (included in installer)
